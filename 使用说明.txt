虚妄编年史 · 使用说明（给小朋友和家人）

═══════════════════════════════════════
  方法一：在自己电脑上玩（推荐，最简单）
═══════════════════════════════════════

第 1 步：安装 Node.js（只需做一次，让家人帮忙）
  - 打开网址：https://nodejs.org
  - 点击绿色的「LTS」下载按钮
  - 下载后双击安装，一路点「下一步」即可

第 2 步：启动网站（每次玩之前做一次）
  - 双击文件夹里的「启动网站.bat」
  - 会自动打开浏览器，进入游戏网站

第 3 步：填入钥匙（只需做一次）
  - 点击网站左下角「⚙️ API 设置」
  - 在「API Key」里粘贴 DeepSeek 的密钥（sk- 开头）
  - 点「保存」

第 4 步：开始玩！
  - 进入「人物图鉴」，选一个角色
  - 点「对话」就可以聊天了

═══════════════════════════════════════
  方法二：放到网上，用手机也能玩（需家人操作）
═══════════════════════════════════════

  1. 把项目上传到 GitHub
  2. 打开 https://vercel.com 用 GitHub 登录
  3. 点「Add New Project」，选这个项目
  4. 在 Settings → Environment Variables 添加：
       名称：DEEPSEEK_API_KEY
       值：你的 sk- 密钥
  5. 点 Deploy 部署
  6. 用 Vercel 给的网址访问，就能聊天（不用填钥匙）

═══════════════════════════════════════
  常见问题
═══════════════════════════════════════

问：聊天显示「API 请求失败」？
答：检查 API 设置里有没有填密钥，密钥是否正确。

问：显示「Failed to fetch」或「405」？
答：不要用 Live Server！请双击「启动网站.bat」打开。

问：DeepSeek 密钥哪里来？
答：让家人在 https://platform.deepseek.com 注册并创建 API Key。
